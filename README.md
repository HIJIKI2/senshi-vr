# 透析室 穿刺トレーニングVR（Meta Quest 3）

Quest 3 のブラウザだけで動作する WebXR アプリです（PC・Unity 不要）。
GitHub Pages などの HTTPS に置けば Quest 3 単体（PC なし）で動きます。Quest のブラウザでブックマークして起動します（一度開けば Service Worker のキャッシュでオフラインでも開けます。Meta Quest ブラウザには一般サイトを「アプリとしてインストール」する機能はなく、アプリ一覧に出したい場合は Meta の Bubblewrap で APK 化してサイドロードします）。

## 内容
- 透析室（臥床した患者、透析装置とモニター、血液回路、点滴スタンド、器具カート、カーテン、窓など）
- デッキ右上にシリンジポンプ（20mL シリンジを横向きにセット、目盛り・押し子・スライダー・バレルクランプ）。シリンジ先端からのヘパリンラインは血液ポンプ入口の手前で動脈側回路に合流する。本体上部のシェルはデッキの後ろに下げ、デッキ上端のチューブが隠れない
- 金属針のクランプは**人差し指の先**をクランプに近づけてトリガー／つまむ で開閉（4cm 以内）。近づくと水色の輪が出る（反対の手に針を持っていても出る）
- 患者のパジャマは首の付け根まで胸元を覆い、鎖骨〜肩の肌も隠す（肩〜胸の断面をスキャンした上半身より高く広くし、上側の超楕円の指数を 3.0 に上げて肩まで高さを保つ。襟の輪は付けない）。`?debug=bust` でパジャマの面より上に出ている肌の頂点をコンソールへ出して確認できる
- 患者: 頭部〜肩は実写 3D スキャン（Lee Perry-Smith head scan / Infinite-Realities, CC BY 3.0）+ 生成した短髪、手は WebXR generic-hand メッシュ（Apache-2.0）に爪とシーン付き皮膚マテリアル、病衣・掛け布団・前腕（毛穴の法線マップ付き皮膚）はコード生成
- 透析装置は日機装 DCS-200Si の製品写真・導入施設の写真（運転中の回路セッティングを含む）を参考に作成: 紺色の台座と 4 輪キャスター、白い丸みのある本体、下部キャビネット両側面の青い縦縞〜ドットの装飾帯と前面の DCS-200Si 銘板、急角度に傾いた白いコンソール面に上から **シリンジポンプ（ヘパリン）／動脈側圧力ポッド接続部／静脈側チャンバーホルダー（左）／血液ポンプ（右上・紫がかった透明カバー、回路は左側から入って左側へ出る時計回り）／返血・サンプルポート／ラインホルダー／気泡検出器 + 静脈クランプ（左下）／補液ポンプ（右下）／透析液カプラのホルダー**。紺ベゼルの 15 インチ タッチパネル（下縁に電源・画面キー、NIKKISO ロゴ、警報ランプ、赤い緊急停止ボタン）、左側面のポールクランプに点滴ポール（2 本フック）。画面は実機の運転画面を模したレイアウトで、血液ポンプは画面右の「運転」キーで開始。位置はベッド頭側の真横（ユーザー左手前）
- 装置内の血液回路（標準のチャンバー回路。導入施設の運転中の写真を参照）も実際の流れどおりに配管: A針 → **気泡検出器（向かって右の A 溝）** → 血液ポンプ（カバーの赤い印のある左下から入り、右側を反時計回りに回って左上へ。回るのは血液ポンプだけで補液ポンプは回らない）→ 出口のチューブはデッキ左上の縁を通って **動脈側チャンバー**（ポール上部・赤キャップ）→ ダイアライザー上端（赤キャップ）→ ダイアライザー内を上から下へ → 下端（青キャップ）→ いったん上へ上がって **静脈側チャンバー**（赤の向かって左隣・青キャップ）の上から入る → チャンバー下端 → **気泡検出器（向かって左の V 溝）** + 静脈クランプ → V針。気泡検出器には A・V の 2 本が横並びで装着される（右 = 赤、左 = 青）。2 つのチャンバーは上から入って下へ抜け、液面の上に少し空気があり（気泡トラップ）、上部のポートから細い圧モニターラインが装置の動脈圧／静脈圧ポートへつながる。回路は治療前から生食で満たされていて（白っぽい半透明）、ポンプ開始でこの順に血液に置き換わる。ダイアライザーはポールの**ダイアライザーホルダー（DLC-05）**に縦置きで、透析液カプラは**同じ色のキャップ側**に接続（赤カプラ = 上の赤キャップ側の側面ポート、青 = 下の青側。ホースは装置前面下部の同色ポートへ） 静脈側チャンバーの出口からの回路はまっすぐ下に出て、デッキ左中の回路ガイド（2 本のクリップ）を通ってデッキ面に沿って下り、気泡検出器の V 溝の真上から溝の向きに入る。ポンプ開始の充填アニメーションは A 回路 → 検出器 → ポンプ → 動脈側チャンバー → ダイアライザー → 静脈側チャンバー（ここで初めて青キャップ側の液が血液に変わる）→ V 溝 → V 回路の順（チャンバーの液は色が個別に変わるので静的結合の対象外。透明な筒は深度を書かず、液を先に描くので、頭の位置で液が消えたり現れたりしない）。デバッグ描画用に `?noui=1` で画面下の案内を隠せる。
- 穿刺側の腕は患者の**右腕**（回外位・掌上向き・母指はユーザー側）。患者側の血液回路は装置前面から垂れ下がり、ベッド縁（アームレストの手前縁）に沿って手元へ、手の母指・示指間に引っ掛けてゆとりを持たせて針へ、と配線される
- 患者の腕は寝たまま自由に姿勢を変えられる: **手首を持つ**と前腕が肘から持ち上がる（最大約 24°）・内外へ振れる（±約 18°）・手をひねると前腕が**回内**して母指側（橈側皮静脈）が上を向く（最大約 90°）。**肘を持つ**と腕全体が肩から外（術者側）へ広がる（最大約 43°）。持ち上げは離すと腕置きに戻り、それ以外の姿勢は保たれる。腕置き（幅広のクッション板と金具）は肩の支点と一緒に回る。腕の形・血管・皮膚はすべて「基準姿勢」（掌を上にして下ろした状態）の座標で定義し、穿刺・エコー・接触・消毒・テープ・血腫などの判定は基準姿勢へ座標変換して行うので、腕の向きを変えてもエコー画像の血管・針の判定・手の接触がそのまま追従する（自己テストで確認）。針が刺さっている間は動かせない
- 肘の周り（前後 3.5cm）を通る血管（尺側皮静脈・肘正中皮静脈・橈側皮静脈の肘側など）は、頂点ごとに前腕と上腕の変換を重みで混ぜて変形する（スキニング）ので、前腕を振ったり回したりしても肘で折れずに滑らかにつながる。位置判定（`P.toArm`/`toWorld`/`frameQuat`）も同じ重みで混ぜるので、表示と判定が一致する
- 針の持ち方は 2 種類: **トリガーで持つ** = 標準（親指と人差し指でつまみ、中指〜小指は軽くこぶしを握る）、**グリップで持つ** = 浅い血管用（つまみ方と針の向きは標準と同じで、中指〜小指だけをパーのように伸ばす。手の甲が少し自分に見える向きにすると親指と人差し指の輪が一番下に来て、伸ばした指が腕に当たらない）。留置針の内筒は、トリガー持ちならグリップ、グリップ持ちならトリガーで抜く。ハンドトラッキングでは、つまんだときに中指〜小指が伸びていれば浅い血管用、握っていれば標準。どちらも針の位置・向きは「コントローラー用の手のつまみ位置」で決める（仮想 gripSpace はコントローラーの gripSpace に較正済み）ので、実際の指先の開き具合に関係なく手に対して同じ位置に保たれる
- ボタン類はトリガーでもグリップでも人差し指が立ち、押し込める
- 術者の手はコントローラーでもハンドトラッキングでも手だけを表示する（袖・手首の筒は付けない）。針を持っている間は指は腕との接触判定をせず（皮膚を押さえている表現として食い込める）、掌だけが腕を貫通しない。浅い角度でも指が腕に当たって刺せないことがない
- エコーのフリーズ: プローブを持っている手の **A か B（左手は X か Y）** を押すとフリーズ（画像・計測が静止、サイドバーは ❚❚ + 緑の Freeze、画像右上に FREEZE）⇄ 解除（▶ + Live）。B/Y は長押しするとリセットなので短く押す。プローブ前面の ⏯ ボタンを反対の手の人差し指で押しても切り替わる（ハンドトラッキング用）。プローブ・聴診器を持っている手のグリップはトリガーと同じく「離す」。プローブを離すとフリーズは解除
- 聴診器のチェストピースは親指と人差し指で縁をつまんで持つ（コントローラー用の手のつまみ位置で決める。`?debug=pinch&tool=steth` で確認）
- エコーで静脈を圧迫すると、血管内の針も血管の中心へ寄る分だけ一緒に動く（針だけ血管の外に見えない）。針は組織の圧縮とも一緒に動く。静脈は押し込み 2.5mm まではつぶれず、最大で 70%（駆血時は最大 10%）扁平化
- エコー上の針: スライス厚（ビームの厚み）を半幅約 2.5mm にして、走査面に完全に入る少し前から針が映り始める。金属針の先端は刃面（約 2.5mm）で先細りに尖り、プラスチック外筒は先端が開いた（丸く閉じない）2 本の壁として映る。画像は 320 px 幅の低解像度 + 強めのスペックルで実機らしいざらつき
- 術者の手は WebXR generic-hand メッシュ。開始時は**素手**で、手指衛生 → 手袋の箱から手袋を取って装着（反対の手に近づける）→ ニトリル手袋の見た目に切り替わる。手袋なしで患者に触れると減点。トリガー/グリップで指が曲がる
- **手は患者の腕を貫通しない**: 指先・指の関節・掌が腕の中へ入ると、手のモデルは皮膚の上へ押し戻される（触れた瞬間に軽い振動）。針を持っているときは手と針が一体で押し戻されるので、**つまんだ指が皮膚に当たる所まで**しか刺さらず、手が腕をすり抜けて深さが分からなくなることがない（針を寝かせるほど深く進められる）。プローブ・聴診器は器具が皮膚で止まり、手がそれに追従する。綿・テープ・駆血帯など器具そのものを皮膚に当てる物を持っているときは判定しない。コントローラーの位置そのものは動かないので、手を上げればすぐ戻る
- **血管タイプ切り替え**: 自己血管（AVF, 手首の橈骨動脈–橈側皮静脈吻合, 推奨刺入角 15〜30°, 駆血あり）/ 人工血管（AVG, 前腕ループグラフト, 推奨 30〜45°, 駆血なし）
- **AVG は解剖どおりのループグラフト**（6mm PTFE）: 肘窩の上腕動脈（分岐の少し上）に端側吻合 → 皮下 5.5mm へ上がり、母指側の脚を遠位へ → 前腕中央で U ターン → 小指側の脚を近位へ → 肘の尺側皮静脈に端側吻合。各脚約 12cm、脚の間隔約 3.5cm。皮静脈・動脈系（分岐・伴走静脈）は AVF と共通。外からはグラフトが皮膚の下のなだらかな畝としてだけ見え、皮静脈は透けて見えない（エコーには全部映る）。エコーでは PTFE 壁が内外 2 本の高輝度線に挟まれた層（double-track sign）として映り、圧迫でつぶれない。吻合部では薄い自己血管の壁（静脈）/ 厚く拍動する壁（動脈）と、二重線のグラフト壁の違いが見える（`?vessel=avg&debug=echo&at=gaa&axis=long` 動脈側、`&at=gva` 静脈側）。穿刺部位は A = 動脈側の脚、V = 静脈側の脚（5cm 以上離す）
- **深い血管モードは AVG でも使える**: グラフトが皮下 12mm になり外からは見えないので、エコーで探して穿刺する（「エコーで描出」ステップ、エコーなしの穿刺は減点）
- **AVF の血管は解剖に沿ったネットワーク**（`src/vessel.js`）: 手首の**吻合部**（橈骨動脈–橈側皮静脈の側端吻合。皮膚の手術痕の下）で橈骨動脈が静脈につながり、前腕橈側皮静脈（母指側を肘へ）→ 上腕橈側皮静脈（上腕外側）、肘窩で分岐する肘正中皮静脈（内側の尺側皮静脈へ）、尺側皮静脈（上腕で深くなる）、前腕正中皮静脈。動脈系は上腕動脈が肘窩のやや内側を下り、**肘の 2 横指下で橈骨動脈と尺骨動脈に分岐**、橈骨動脈は吻合部に向かって浅くなり流入動脈として拡張、尺骨動脈は小指側を手首へ。各動脈の両脇には**伴走静脈**が 2 本ずつ走る（深部静脈。エコーでは圧迫でつぶれ、動脈はつぶれない。穿刺対象ではない）。動脈・伴走静脈はエコーにのみ映り、動脈の誤穿刺は減点。発達した皮静脈は皮膚からわずかに盛り上がって透けて見える
- **駆血で怒張**: 橈側皮静脈の半径は非駆血 3.2mm → 駆血 4.5mm（各枝の基本径は駆血時の値）。表示用の筒は実際の径より 2.2mm 太く、駆血すると皮膚から盛り上がって透けて見える
- **静脈の径は一様ではない**: 太い所（怒張・瘤状）と細い所があり、穿刺対象の枝には穿刺部位から 2.5〜3.5cm 離れた所に**狭窄**（最大 60% 細い）が毎回違う位置に作られる。エコーで見るとその部分だけ細く映るので、太い所を選んで刺す練習になる（狭窄部に刺すと「狭窄部に穿刺」で減点、血管が細いので後壁穿破もしやすい）
- **穿刺部位は毎回変わる**: 前腕橈側皮静脈の手首寄り／中央／肘寄り、肘正中皮静脈、上腕橈側皮静脈の組み合わせ 6 パターンからリセットごとにランダムに選び、手順パネルに部位名を表示
- **血管の深さ切り替え（深い血管 = エコー下穿刺）**: サイドテーブル 3 番目の紫キー。皮静脈（AVG ではグラフト）が 1cm 強の深さになり透けて見えなくなるので、エコーで描出してから穿刺する（「エコーで血管を描出」ステップが追加され、エコーなしの穿刺は減点）
- **エコーガイド下穿刺**（`src/echo.js`）: 富士フイルム iViz air（10.1 インチ タブレット + ワイヤレス リニアプローブ FWTL10-5）を再現。プローブは製品写真を参考に、幅広で薄いヘッド（58mm × 19mm 厚）・細い握り（40mm 幅）・丸い下端、前面に「10-5」表示・親指の溝・電源/フリーズボタン・バッテリー LED・FUJIFILM ロゴ・無線マークを作り込み、**ヘッドの前面・背面と両側面の中央に白い▼のセンターマーク**（走査面の中心 = 画像上端の▼）を付けた。短軸ではこのマークの位置に刺すと針が画像の中央に出る。プローブはカートのベッド側の端のプローブ立てにあり（持ち手を握って取る）、持って皮膚に当てるとタブレットに B モード画像がリアルタイムに映る。タブレットは固定されておらず、手で持って好きな所に置ける（離すと、ほぼ水平なら画面上向きに寝かせ、それ以外は 20° 後ろにもたれた状態で立つ。ベッドの上・患者の体と腕の間に立て掛ける・カートの上など）。初期位置はカートのベッド側の端（画面を上にして寝かせてある）
  - 画像はプローブの走査面（幅 38mm × 深さ 30mm）で腕を切った断面を GPU で合成: 皮膚の高輝度線、皮下脂肪（低輝度 + 隔壁）、筋膜、筋（羽状の筋線維）の背景の上に、**設定された血管だけ**が構造として映る（シミュレーターなので骨などは描かない）: 無エコーの内腔、静脈は薄い壁で圧迫すると扁平化、動脈は厚い壁で拍動、吻合部では動脈と静脈の内腔がつながって見える、狭窄部は細く映る。後方エコー増強・側方陰影、スペックル、深部減衰。プローブが皮膚から浮いた列は信号なし。押し込むと皮膚はレンズ面に密着したまま浅い組織が圧縮され（画像の上端は切れない）、静脈は軽い接触（約 1.7mm まで）ではつぶれず、強く押すほど扁平化（5mm で 85%）。駆血で怒張した静脈はほとんどつぶれない。動脈はつぶれない。静脈の上端は皮膚の 0.8mm 下にあり、押し込んでも画像の上端で切れない。血管は約 6mm の線分の連なりで表現し、走査面の近くの線分だけを GPU に渡して「表面までの符号付き距離が最小の線分」で内腔/壁を決める（短軸でスライドしても継ぎ目が輪として映らない）
  - 針: 金属部分は高輝度（短軸で点、長軸で線）で、その真下に針の幅の**黒い音響陰影**が伸びる（深くなるにつれ徐々に薄れる）。多重反射は針のすぐ後ろにごく弱く出るだけ。ビームと直交するほど明瞭で、急角度では見えにくい。留置針のプラスチック外筒は前壁・後壁の 2 本の線（短軸では輪）として金属より暗く映り、内腔は暗く陰影はごく弱い。内筒抜去後は外筒だけが残って見える
  - 階調は実機同様の対数圧縮（ダイナミックレンジ圧縮）で、低輝度の組織が持ち上がり高輝度は飽和に近づく。近距離音場はやや明るく、深部はやや暗い
  - 画面は iViz air の UI（上バー、左の Freeze・PV 穿刺モードの Depth to center / Diameter、L10-5、センターライン ▼、F マーク、深度目盛）。センターラインに最も近い血管を自動計測して楕円と深さ・径を表示
  - 短軸（血管を横切る）で血管を画面中央に置いて針先を追う、長軸（血管に沿う）で針全体を見る、の両方が可能
- **消毒範囲の表示**: アルコール綿で拭いた所が皮膚に薄い琥珀色（艶あり、重ね塗りで濃くなる）で描かれ、穿刺点がその範囲内かを判定（範囲外は減点）。拭いた距離 12cm で 100%（直径 5〜7cm を 2 周ほど）。印はレイヤーのテクスチャを `flipY=false` で貼り、断面の並びを等間隔に取り直して描くので、拭いた所と色の付く所が一致する（以前は腕の長さ方向に鏡像の位置へ出ていた。`?debug=swab[&hide=1]&seed=N` で確認）。アルコール綿のパウチはカートの端に 4 枚（2 × 2）
- **針タイプ切り替え**: 金属翼状針 / プラスチックカニューラ型留置針（逆血確認 → 2〜3mm 進める → 内筒（金属針）を抜去して外筒を留置）
- 切り替えはユーザー左後方のサイドテーブルにある設定パネルのボタン（押すとリセット）、または URL の `?vessel=avg&needle=cannula`
- **物理ボタン**: 何も持たずにトリガーを引くと人差し指を立てた姿勢になり、その指先でボタン（リセット×2・設定パネル・装置のポンプ開始キー）を押し込むと実際に沈んで動作する。手指消毒薬のポンプヘッドだけはトリガー不要で、掌や指で押し下げるだけで動く
- 器具カートは穿刺者の右側、長辺（前面）を穿刺者に向けて配置（幅 1.2m。`src/constants.js` の `TRAY` / `TRAY_W` で位置・向き・幅を調整可能）。ベッド側の端から順に **エコー（タブレット・プローブ立て・ゼリー）→ 聴診器・駆血帯・テープ → リセットボタン・穿刺セット・針 → 開始セット**（手指消毒薬・ニトリル手袋の箱・個包装アルコール綿 ×2）と並び、器具同士は重ならないよう間隔をとっている
- `?test=grab` で全器具の「掴む」自己テストを実行（AVF 50 項目 / AVG 48 項目: 針の 2 つの持ち方（グリップ持ちで中指〜小指が伸び、つまみ位置が指より下）、 腕の姿勢変更（手首を持って上げる・振る → 離すと持ち上げだけ戻る、肘を持って外転）、腕を回した状態での座標変換の往復・針先の血管内判定・エコーの中央描出・手の皮膚停止・駆血帯の装着、掴める物の水色の輪、ハンドトラッキングの手ぶれ平滑化、手が腕を貫通しない・針を持った手が皮膚で止まっても針先は血管に届く・綿を持った手は押し戻さない・ハンドトラッキングが途切れても持った物を離さない・仮想 gripSpace がコントローラーと一致、各器具の掴み中心に手のモデル付きの仮想コントローラーを置いてトリガー → 手に移る／離すと戻る、プローブは 3 か所 + エコー画像生成 + 皮膚で止まるか、留置針の内筒抜去（ハブ近くでトリガー / ハブをつまむ）、テープを反対の手の甲に貼る→自分では掴まない→反対の手で剥がす→離すとカートへ戻る、駆血解除後も針先が血管内に残るか、プローブが離した所に置かれる／立ての近くなら戻る。結果はコンソールと情報欄）
- 左右どちらの手でも器具を持てる（左利き対応）
- 手順（金属翼状針）: 手指衛生 → 手袋装着（両手）→ 聴診 → 触知（スリル）→ セット開封 → 滅菌シーツ（前腕を持ち上げて敷くとスムーズ）→ アルコール綿のパウチを開封して綿を取り出し消毒（綿を皮膚に当てたまま中心から外へ円を描く。浮かせていると色は付かない。2 枚目の綿でも拭けるので A・V 両方の穿刺部を消毒する。使った綿は離すと膿盆へ）→ 駆血（AVF のみ, 1 分以内）→ **V針穿刺**（逆血後に寝かせて進め、離すと留置）→ V針テープ固定（横一文字 + Ω固定）→ V針クランプ開放で逆血をチューブ先端まで上げて再び閉じる → A針も同様 → **駆血帯を外す**（AVF）→ A/V 回路接続 → クランプ開放 → 血液ポンプ開始（A針 → 回路 → ピロー → ポンプ → ダイアライザ → チャンバー → V針 の順に血液が満ちていくアニメーション）
- **運転の条件**: A針（赤回路）の先端が血管内にないと脱血できず「脱血不良アラーム」で運転できない。V針（青回路）の先端が血管外のまま運転すると、返血が皮下に漏れて穿刺部が腫れ、静脈圧上昇アラームでポンプが止まる（減点。抜針して再穿刺）。駆血帯を外して静脈が細くなっても、留置した針の先端は血管の軸上にあるので血管内に残る（自己テストで確認）
- 手順（カニューラ型留置針）: 穿刺 → 内筒抜去（留置した針のハブ付近でトリガー、またはハブをつまむ操作。持ったままならグリップボタン）→ テープ固定 → 逆止弁付きなので回路を直接接続 → ポンプ開始
- 患者はパジャマ姿の仰臥位。胴体は肩幅 → 大胸筋のふくらみ → 胸郭の下で細くなる → 腹部と断面が変わる超楕円の曲面で、背面はマットレスで平らになる（前立て・ボタンは表面に沿う）
- 穿刺は原則 V（返血側）から。A針は V針の固定後。駆血したまま回路を接続すると減点
- 手順の前後関係（依存関係）だけを評価するので、臨床で許容される順序の違いは減点されません（順番違いは −2）
- **採点は初心者向けに緩め**: 各減点は従来の半分（後壁穿破 −12、動脈誤穿刺 −8、消毒なし −10、角度・位置 −5/−2 など）。同じ内容の減点を繰り返したときはさらに半分（最低 1 点）。皮膚の固定なし・逆血後に針を寝かせていない（自動で寝かせる）・逆血後に進めずに内筒を抜去・刺入角度、は減点しない（持ち方・刺し方は術者の流儀に任せる。角度は記録に残る）。
- **刺し直し**: 回路を接続した後でも、コネクタに手を近づけてトリガーで回路を外せる（手に持った状態。離すと装置側へ戻る。運転中なら停止して −5）。針に貼ったテープも同様に剥がせる（離すとカートへ戻る。針の上で離すと貼り直し）。回路を外してテープを全部剥がすと針を持ち直して抜ける。抜針するとその針の手順（穿刺・内筒抜去・テープ・逆血・接続・クランプ）がやり直しになり、ボードと音声も戻る。脱血不良アラームの案内もこの手順を示す終了時に 90 以上「優」、70 以上「良」、50 以上「可」、それ未満「要再挑戦」と表示。初めてでも 50 点前後は残り、慣れれば 90 点以上を狙える基準
- **タスクボード**（ベッド頭側の向こう、約 1.45m 先）は 1.28 × 1.1m。手順は 1 行約 3cm、「次:」の見出しは 4cm、やり方 2.9cm、記録 4 行（長い行は自動で縮小・省略）。視力が低くても近寄らずに読める大きさ
- **音声ガイド**: 手順が進むたびに次の手順（名前とやり方）、減点の内容、終了時のスコアを読み上げる。括弧の中（操作の補足）は読まない。触知の手順は短い説明（`say`）を読む。読み上げ中に手順が進んだら今の読み上げを止めて次の手順へ移る。最初の手順は「まず、…」で始まる（「まずは」は合成音声の先頭に短い破裂音が出るため）。生成後に、本体から 0.6 秒以上離れた短い音（尺合わせの「う」）を切り落とし、先頭に短い音と切れ目が出た文は乱数を変えて作り直す（最大 4 回）。合成は 1 文（「。」まで）ずつ行う（まとめると読みが崩れたり、文の間の長い無音で末尾の掃除が次の文を切ったりする）。終了のスコアは点数ごとに 1 文（「トレーニング終了。スコアは、81 点、良、です。」）で 101 クリップ。ブラウザ内蔵の合成音声（Web Speech API）で、端末内の日本語音声を使うので無料・通信不要。サイドテーブルの 4 つ目（橙）のキー「音声ガイド」で ON/OFF（既定 ON、`?voice=0` で OFF 起動）。端末に日本語音声が無いときは**同梱の音声ファイル**（`assets/voice/`、約 190 クリップ）に自動で切り替わる（`?voice=clips` で強制、`?debug=voice` で端末の音声一覧を console に出す）。同梱音声は Irodori-TTS（Aratako 氏、MIT、日本語特化の合成音声）の VoiceDesign で「落ち着いた 20 代半ばの女性アナウンサー」を指定して `tools_voice.py` で一括生成（手順文は `?dump=voice` で全設定ぶんを書き出したもの、減点文・スコアの数 0〜100・評価は同スクリプト内）。医療用語は読み仮名辞書でかなに変換してから合成し、Whisper で読みを確認。Opus 24kbps mono、合計約 3MB
- 評価項目: 穿刺位置、逆血後の寝かせ・進め、後壁穿破（血腫）、A-V 間隔、消毒の方法（中心から外側へ）、駆血時間、クランプ操作（逆血確認・流出・接続時の閉鎖）、未固定での接続、ポンプ開始時の回路状態
- 判定: 穿刺位置、逆血（フラッシュバック）、後壁穿破（血腫）、A-V 針の間隔、手順の順番、消毒/駆血の有無 → スコア表示
- シャント音は WebAudio で合成（手首の吻合部に近いほど大きい、拍動に同期）

## タイトル画面
起動時と VR 開始時は白い部屋のタイトル画面。目の前の上に「穿刺VR powered by HOSPY CE」の **3D ロゴ**（ロゴ画像（3 代目のデザイン「穿刺トレーニングVR」）から白背景を除いた輪郭を OpenCV で抽出して `assets/ctrl/logo_shape.json` に保存し（イラスト内部の白いハイライト＝ゴーグルのレンズや針の光は穴にせず前面に描く。穴として残すのは文字の内側とエンブレムの大きな背景の隙間だけ）、three.js で 7cm 押し出し。幅 5.4m・3.0m 先・高さ 2.5m。前面は元の絵柄を照明の影響なしでそのまま（白飛びしない）、側面は紺。ゆっくり浮き沈み）、手を伸ばして届く所（前 0.6m・高さ 1.32m = 胸の高さ）に幅 0.7m の 1 枚のパネル（キーの判定はそれぞれの矩形の中だけで、隣のキーやスタートを巻き込まない）: 上段に **血管（AVF/AVG）・穿刺針（金属翼状針/カニューラ型留置針）・深さ（標準/深い）** を選ぶ大きなキー、下段に大きな **スタート** キー。キーはトリガーかグリップを握って人差し指を立てた手（ハンドトラッキングは常に）で押す。スタートを押すと透析室が現れ、選んだ設定で最初から始まる。ロゴとパネルは頭の追跡が有効になってから 2.5 秒間は頭の正面に追従してから固定される。パネルのキーは血管・針・深さ・音声ガイド（ON/OFF）の 4 つ。壁の説明板の最下行（掲示場所の案内）は削除。スタートを押したとき頭の向きを基準に開始位置（ベッド脇、ベッドを向く）へ立ち直し、目の高さが立位より低ければ（座ったまま等）立位の目の高さ 1.62m まで持ち上げる。透析室内の設定パネルのキーは「物のリセット付きで設定を切り替える」、その下の赤いボタンは**タイトル画面へ戻る**（物をリセットし、立ち位置を原点に戻して、起動時とまったく同じ経路でタイトルを出す。ロゴとパネルの位置・見た目は起動時と同じ）。B/Y 長押しは物のリセットだけ。タイトル画面でもスティックで移動・向き・高さを変えられる。確認用パラメータ（test/debug/demo/cam など）付きのときはタイトルを出さず、`?title=1` で表示。

## 操作
操作説明は**術者の真後ろの壁**（幅 2.6m の掲示板）に常に掲示してあります。左列は Meta Quest Touch Plus コントローラーの製品写真（`assets/ctrl/`、Meta の製品ページより。右は引き出し線でスティック・A/B・トリガー・グリップを示し、左は小さく掲載）と各操作、右列はハンドトラッキングの各操作。振り向けばいつでも読め、消えません（デスクトップは `?cam=0.1,1.5,0.9,0.1,1.55,3`）。

入力はコントローラーとハンドトラッキングを自動で切り替えます（入力源がつながるたびに判定）。ハンドトラッキングの操作性向上: 掴む基準点は親指と人差し指の指先の中点（つまむ所）、仮想 gripSpace は One Euro フィルタで平滑化（静止時のジッター約 1/4、30cm/s の動きで遅れ 2〜3mm）、何も持っていない手の近くで掴める器具（と患者の手首・肘）に**水色の輪**を表示、振動の代わりに短い効果音（触れた／持った／ボタン／手順完了／減点）。**ハンドトラッキング中に手がカメラの外へ出て追跡が途切れても（針を持ったまま別の方向を見た等）、持っている物は離しません**（追跡の途切れによる「つまみ解除」は無視し、手が戻ったら持ったまま続けられる。離したいときは手が戻ってからもう一度つまむ）。器具の持ち位置は、コントローラー用の手のモデルの関節をそのままハンドトラッキングの関節として与えたとき仮想 gripSpace がコントローラーの gripSpace に一致するよう較正してある（原点 1〜2mm・軸 0°、自己テスト）。Quest 3 でコントローラーを置いて手を出すと、実際の手の形がそのまま手のモデルに映り、親指と人差し指をつまむ動作がトリガー（持つ／離す）になります。器具を持つ位置・向きは、関節（手首・指の付け根）から作った仮想の gripSpace / targetRay を使ってコントローラー時と同じ計算で決めるので、針・プローブ・手袋などはコントローラーと同じ持ち方になります。ボタンは人差し指で直接押せます。振動とスティック移動は使えません（歩いて近づく）。PICO 4 などハンドトラッキングを WebXR に出さない機種ではコントローラーのみです。振動は `hapticActuators[0].pulse()` と `vibrationActuator.playEffect()` の両方を試します（機種のブラウザが対応していなければ鳴りません）。

| 聴診器 | チェストピースを持つとイヤーチップが垂れ下がる。頭に近づけると耳に装着され、ダイアフラムを血管に当てると音が聞こえる。どこで離してもカートへ戻る |
| 針 | 逆血（フラッシュバック）後に寝かせて 2〜3mm 進め、トリガーを離すと留置される（持ち直して調整も可） |
| 器具を腕の上で離す | シーツ → 腕の下に敷く、駆血帯 → 上腕に巻く |
| 患者の手首に手を近づけてトリガー | 手首を持ち、手を上げると前腕が肘から持ち上がる（最大約 24°）、内外へ動かすと前腕が振れる、手をひねると前腕が回内外する。離すと持ち上げだけゆっくり戻り、向きは保たれる。針が刺さっている間は不可 |
| 患者の肘に手を近づけてトリガー | 肘を持ち、外へ動かすと腕全体が肩から広がる（腕置きも一緒に回る） |

| アルコール綿のパウチを持ち、反対の手で開封口に触れてトリガー | 1 回目で開封（帯が千切れて綿が顔を出す）、2 回目で綿を取り出してその手で持つ。開封済みパウチ・使用済みの綿は離すと下段の膿盆へ |
| 上腕の駆血帯に手を近づけてトリガー | 駆血帯を外す（手に持った状態になり、離すとカートへ戻る）。両針の留置後に外すとステップ完了 |
| 空いた手で前腕の血管に触れる | スリルを触知（1 秒で完了。聴診は 3 秒）。指先の判定点はコントローラー用の手のモデルの tip ボーンではなくメッシュの先端（ボーンから 11mm 先。`?debug=hand` で計測）で、ボタン押しやクランプの判定も同じ点を使う。手順「スリルを触知」の間（学習モード）は開いた手（トリガー・グリップなし）で触れるだけで、人差し指か中指の先から 1.5cm 以内に血管があれば拍動に合わせて振動。手順を終えた後（穿刺時）は、トリガーかグリップで人差し指を立てた指先の真下に血管の内腔がある（横ずれが半径の 90% 以内）ときだけ振動し、感じた所の真下へ垂直に刺せば必ず血管に入る。針やプローブを持つ手には伝わらない。ハンドトラッキングは人差し指だけ伸ばした形 |
| 穿刺時に反対の手を穿刺部の近くに置く | 「皮膚を伸展・固定して穿刺 ✔」と記録される（減点対象ではない。エコー下穿刺では反対の手がプローブを持つため） |
| 針を持つ | 親指と人差し指の腹で挟む姿勢。金属針は折り畳んだ翼の両面を、留置針は内筒ハブ（後端の硬い部分）を挟み、針の軸は人差し指の向きに沿って指先の先へ出る。刃面（翼）は手の甲側が上。中指以降は軽く曲げる |
| エコープローブ（カートのベッド側の端） | 持つと手全体で本体を握る（広い面が掌に当たり、親指は手前の広い面、他の指は向こう側へ回り込む）。持ち手は親指の方向（コントローラーを自然に構えた握手の形なら真上）へ伸びるので、手首をひねらなくてもプローブは垂直に垂れ下がり、レンズ面は握った手の小指側の 2cm ほど下で真下を向く（指はすべてレンズ面より上）。皮膚に触れると振動し、それ以上押し込んでもプローブは皮膚の上に留まって腕の表面を滑る（3mm までは圧迫で静脈が扁平化、深く押し込むと小刻みに振動）。浮かせると何も映らない。血管を横切る向き = 短軸、沿わせる向き = 長軸 |
| エコーのタブレット | 持って好きな所へ。離すと置いた面（ベッド・布団・アームレスト・カート・サイドテーブル）の上に、立てて（20° 後傾）または寝かせて置かれる |
| 聴診器を腕に当てる | ダイアフラムは皮膚で止まり（1mm まで沈む）、それ以上押し込んでもチェストピースは腕を貫通せずに皮膚の上を滑る |
| エコープローブを離す | 離した所に広い面を下にして横たわる（ベッド・布団・患者の腕の上・カート・サイドテーブル）。プローブ立てから 15cm 以内で離すと立てに戻る。持ち上げるとエコーが再開 |
| 針を持ち血管へ刺入 | パネルに角度・深さを表示。逆血を確認したらトリガーを離すと固定 |
| カニューラ針: 逆血後に反対の手で内筒ハブをつまむ（トリガー）/ 持っている手のグリップ | 内筒を抜去して外筒を留置。その後トリガーを離して固定 |
| テープを針の上で離す | 翼（金属針）/ ハブ（留置針）をテープ固定（テープに最も近い留置針に貼る。隣の針が 2 枚貼り済みでも翼の上なら確実に貼れる）。テープは腕の曲面に沿って皮膚に密着し、翼・ハブの上だけ盛り上がる。2枚目はチューブ（Ω固定）/ハブ後端 |
| テープを反対の手の甲の近くで離す | 手の甲（手袋の上）に貼っておく（最大 4 枚、手首側へ並ぶ）。穿刺後に反対の手をテープに近づけてトリガーで剥がし（手か指先がテープから 8cm 以内なら最優先。隣に留置した針があっても針は掴まない）、針の上で離して固定する。自分の手の甲のテープは自分では掴めない。例: 右利きなら左手の甲に貼っておき、針が刺さったら右手で剥がして固定 |
| 装置から垂れた回路コネクタ（赤/青）を針のコネクタに合わせて離す | 回路接続 |
| 針のチューブのクランプに手を近づけてトリガー | クランプ開閉（金属針）。留置後に開くと逆血が上がり、閉じて接続、接続後に再び開く |
| 留置針の内筒ハブに手を近づけてトリガー | 内筒抜去 |
| ボタン全般 | 何も持たずにトリガーを引く（指差し姿勢）→ 指先でボタンを押し込む。底まで沈むと動作し振動する |
| 透析装置のタッチパネル「運転」キー | 血液ポンプ開始（未接続・クランプ閉のときはアラームで減点）。画面が「運転 HD」表示に変わり、ポンプのローターが回る |
| 手指消毒ポンプのヘッド（開始セット） | 手指衛生。トリガー不要、掌や指で押し下げる |
| 左スティック | 移動（頭の向き基準） |
| 右スティック 左右 / 上下 | 30° スナップターン / 自分の高さの調整 |
| B または Y ボタン 長押し（1秒） | どこからでもリセット |
| 左後方サイドテーブルの青/緑/紫キー | 血管タイプ（AVF/AVG）・針タイプ（金属/カニューラ）・血管の深さ（標準/深い＝エコー下穿刺）の切り替え |
| 器具の持ち方 | 基本はトリガーを押している間だけ持ち、離した瞬間に置く／貼る／留置する。**エコープローブと聴診器だけ**は長く使うので、トリガーで持ち、もう一度トリガーで離す（押し続け不要）。聴診器はどこで離してもカートのトレイへ戻る（イヤーチップも外れる） |
| 赤い押しボタン（カート前面・サイドテーブル） | リセット |

## 起動方法（開発・社内配布）
1. PC と Quest 3 を同じ Wi-Fi に接続
2. このフォルダで `python serve.py` を実行 → 表示された `https://<IP>:8443/` をメモ
3. Quest 3 のブラウザで URL を開く（自己署名証明書の警告 →「詳細設定」→「アクセスする」）
4. 「VR を開始」を押す
5. 単独起動したい場合: `dist` フォルダの中身を GitHub Pages（Public リポジトリ → Settings → Pages → main / root）に置き、Quest のブラウザでその URL をブックマーク。以降はブラウザ → ブックマークから起動（一度開けばオフライン可）。アプリ一覧から起動したい場合は Meta の Bubblewrap（@meta-quest/bubblewrap-core）で APK を作ってサイドロード

### 証明書の再作成（必要な場合）
```
"C:\Program Files\Git\usr\bin\openssl.exe" req -x509 -newkey rsa:2048 -nodes -keyout certs/key.pem -out certs/cert.pem -days 3650 -subj "/CN=localhost"
```

### 外部の人に一時的に試してもらう（Cloudflare Quick Tunnel）
`share.bat` をダブルクリック（または `python share.py`）すると、このフォルダをローカル配信しつつ `https://xxxx.trycloudflare.com` の公開 URL が表示されます。
- 正規の証明書が付くので PICO 4 / Quest のブラウザで警告なしに開けます（PICO Browser も WebXR 対応）
- URL は起動のたびに変わり、ウィンドウを閉じる／Ctrl+C で無効になります。PC を起動したままにしてください
- 誰でも開ける URL なので、相手にだけ直接伝え、試用が終わったら閉じてください
- 初回のみ `winget install --id Cloudflare.cloudflared --source winget` で cloudflared を導入（導入済み）
- PICO 4 では「B/Y 長押しでリセット」のボタン番号が異なる可能性があります。効かない場合はカートの赤いリセットボタンを使ってください

### 代替: GitHub Pages / 任意の HTTPS ホスティング
フォルダをそのまま公開すれば証明書警告なしで利用できます。

## デスクトップでの確認
PC ブラウザでも見学できます（マウスで視点操作）。`?cam=x,y,z,tx,ty,tz` でカメラ位置、`?debug=1` で手のモデルを表示、`?demo=1&flow=9` で穿刺・接続・ポンプ開始済みの状態を表示（`flow` の秒数で充填の途中経過）、`?lift=0.35` で前腕を持ち上げた状態、`?pose=外転,内外,持ち上げ,回内`（rad）で腕の姿勢を指定（例 `?pose=0.5,0.15,0,0.6`。`debug=echo` や `demo=1` と併用可）、`?stats=1` で描画回数をコンソールへ（`&nomerge=1` で静的メッシュの結合なし）を表示。`?debug=echo` でプローブを V 側の穿刺部位に当てた状態（`&axis=long` 長軸、`&needle=1&nadv=0.03&nang=25` で針を刺した状態、`&deep=1` で深い血管、`&at=ana` 吻合部、`&at=sten` 狭窄部、`&at=bif` 上腕動脈の分岐部、`&press=0.003` 押し込み量、`&needle=cannula&ndl=1&stylet=out` 外筒だけが残った留置針、`&dx=0.02` 部位から腕に沿って 2cm ずらす、`&freeze=1` フリーズ画面）、`?debug=pinch` で針の持ち方（`&hold=ok` で浅い血管用の OK サイン持ち、`&tool=probe` でプローブの持ち方と手の甲のテープ、`&pose=hs` で握手の形の手）を表示。

## 描画負荷（Quest 3 での FPS）
- 動かない物（部屋・ベッド・カート・装置の静的部品・奥のステーション）は起動時に材質ごとに 1 メッシュへ結合（`mergeStatic`）: 描画回数 432 → 223（患者側の視点）
- 影は PCF（ソフト PCF の半分のサンプル）、影カメラは作業域 ±2.4m に絞る、奥のステーションは影を落とさない、固定中心窩レンダリング最大
- エコー画像は 1 フレームおきに生成（実機の約 30 フレーム/秒相当。計測・接触判定は毎フレーム）、タブレット画面の枠は 1 秒ごと・計測オーバーレイは変化時と 10 回/秒、手順パネルは変化があったときだけ描き直し
- 駆血の怒張の遷移中に血管の筒を毎フレーム作り直さない（1.2% 以上の変化で再生成）
- 対応していれば 90Hz を要求し、実測が目標の 88% を下回る状態が続いたら 72Hz に切り替える（コマ落ちする 90 より安定した 72 の方が滑らか）
